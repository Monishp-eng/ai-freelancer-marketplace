# AI-Powered Freelancer Marketplace

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Monishp-eng/ai-freelancer-marketplace)

A modern full-stack MERN (MongoDB, Express.js, React, Node.js) platform connecting clients with skilled freelancers, powered by NLP-based TF-IDF project matching, Socket.IO real-time communication, and Stripe escrow milestones.

## Features
- **AI Matching**: Natural.js TF-IDF vectorization matches freelancers to project requirements
- **Escrow Milestones**: Secure payment flow and milestone approval pipeline
- **Live Communication**: Real-time messaging and status updates via Socket.IO
- **Role-Based Portals**: Dedicated experiences for Clients and Freelancers
- **One-Click Demo Access**: Instant demo login as Client or Freelancer

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Socket.IO Client
- **Backend**: Node.js, Express.js, Socket.IO, Mongoose, Natural.js, Stripe SDK
- **Database**: MongoDB Atlas
